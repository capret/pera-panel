Replace world save

Up to 256 MiB. Zip one Cluster folder, or its contents, with Master/save and optional Caves/save inside. For Steam Cloud saves, extract Master.zip and Caves.zip into those folders first.

Include each shard’s modoverrides.lua beside its save folder. If neither file is present, inheritance imports an empty mod list. If both files are present, they must use the same settings.

The current world will stop and a safety backup will be created. Existing progress is replaced. Caves are enabled only if the uploaded save includes them. Your token, player lists, and other panel settings are kept. Enabled mods download on the next start.
