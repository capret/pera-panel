How backup and restore work

Backup restoration replaces world progress and settings, stopping and restarting a running world. Your current token and boot preference are kept. A safety backup is made first.

Backups stay on this server until you delete them. Copy important backups to another machine.

Import local save

Replace this world with a ZIP from your computer. A safety backup is created first.

Download saved game

Keep a copy on your computer, or upload it again with Import local save. Includes surface and cave progress, player saves, and mod settings.

Stop the world before downloading to keep both shards consistent. Server tokens and passwords are excluded. ZIP limit: 256 MiB.

Native game rollback

Return to an earlier in-game snapshot. The world must be running.

Rollback details

DST reloads the world; players may see a loading screen or reconnect. Available snapshots and the result are controlled by the game. This does not restore panel settings or create a panel backup.

Recover an imported characterUse when an imported character does not load after joining online.

Stop the world first. Select two saves in the same shard and session.

How to create a destination save
  1. Start this world and join online with your Klei account.
  2. If your original character loads, keep playing. No recovery is needed.
  3. If you see character selection, create a temporary character, then leave and stop the world so its save is written.
  4. Refresh saved characters. Select the original as the source and the temporary character as the destination.
The destination is backed up before replacement.

ZIP requirements

Up to 256 MiB. Zip one Cluster folder, or its contents, with Master/save and optional Caves/save inside. For Steam Cloud saves, extract Master.zip and Caves.zip into those folders first.

Mod import details

Include each shard’s modoverrides.lua beside its save folder. If neither file is present, inheritance imports an empty mod list. If both files are present, they must use the same settings.

The current world will stop and a safety backup will be created. Existing progress is replaced. Caves are enabled only if the uploaded save includes them. Your token, player lists, and other panel settings are kept. Enabled mods download on the next start.
